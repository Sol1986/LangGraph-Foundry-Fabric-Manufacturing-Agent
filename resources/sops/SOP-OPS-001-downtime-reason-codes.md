# SOP-OPS-001: Downtime Reason Codes

| Code | Meaning |
|---|---|
| OVERHEAT | Machine stopped by a thermal alarm or shutdown |
| MECH_FAILURE | Mechanical breakage or jam |
| ELECTRICAL | Electrical fault on the machine |
| SENSOR_FAULT | Sensor or controller fault |
| MATERIAL_WAIT | Line waiting for a component or material |
| CHANGEOVER | Product or tooling changeover |
| PLANNED_MAINT | Scheduled maintenance window |
| OPERATOR_DELAY | Operator or staffing delay |
| QUALITY_HOLD | Line held for a quality check |
| POWER_OUTAGE | Loss of site or line power |

Operators select the code at the time of the stop. Codes describe the symptom, not the underlying root cause.
