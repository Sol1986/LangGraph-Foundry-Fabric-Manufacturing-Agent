# SOP-SUP-002: Component Shortage Escalation

Every stocked component has a reorder point per plant.

1. When on-hand stock falls below the reorder point, purchasing places a replenishment order the same day.
2. If on-hand stock falls below 25 percent of the reorder point, the plant manager is notified and lines that consume the component are placed on material watch.
3. Lines waiting for material log downtime under reason code MATERIAL_WAIT.
4. Expedited freight may be authorised by the plant manager when a shortage is projected to stop a line.
